# Hi3D Agent Skills (`hi3d-skills`)

Official collection of AI Agent Skills for [Hi3D](https://docs.hi3d.ai) 3D Model Generation.

## Skills Included

### `hi3d-generate`
Enables AI agents (Antigravity, Cursor, Claude, etc.) to generate 3D models (GLB, OBJ, STL, FBX, USDZ, 3MF) from 2D images, reliefs, splitting, and multicolor meshes via `hi3d-cli`.

## Installation

Add skill to your AI Agent environment:

```bash
npx -y skills add MIt9/hi3d-skills/hi3d-generate
```
